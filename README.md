# Geometría — apuntes animados

Material de apoyo para las monitorías de Geometría (IIG127A). Cada tema del ramo
explicado con figuras que se mueven: se elige la unidad, se elige el tema que
complica, y se ve cómo se arma.

**→ https://mati3939.github.io/geometria-udd/**

## Cómo se usa

- Las unidades están en la barra de arriba. Al pasar el cursor por una se abre la
  lista de sus temas.
- Dentro de un tema, las figuras se mueven con **▶ Reproducir** y los deslizadores
  cambian los datos del dibujo.
- Teclas `1` a `9`: saltar entre los temas de la unidad actual. `Inicio`: volver al
  mapa del ramo.
- Botón 🌗: claro, oscuro o automático.
- Cada tema tiene su propia dirección (`#identidades-fundamentales`), así que se
  puede compartir el enlace de uno puntual.

Funciona igual en el teléfono y en el computador, y una vez cargada no necesita
conexión.
